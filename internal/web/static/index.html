Calibrated field strength uses the meter's Direct Input jacks on the rear panel, not the couplers. Range is −15 to +33 dBm (max input 2 W). To use this mode, enable Direct Input (FS) in the meter's SETUP → Opt. Mode Display and feed signal directly to the rear-panel input.

Peak / Average / Ratio derived client-side over a rolling 2-second window of samples. The meter itself reports a single power value per poll; peak ≈ max(window), avg ≈ mean(window), ratio = 10·log₁₀(peak / avg). Indicates speech-processing compression — higher ratio = less compression.
Read-only reference. The LP-100A serial protocol only exposes A / M / F / P; there is no remote-setup command. To change any of these, press & hold Mode on the physical meter for ≈1 s, then use Mode (next) / Alarm-Dn (lower) / Peak-Up (raise).
